# Launch page

This folder contains a simple launch hub for the meme coin project.

## How to view it

Open [index.html](index.html) in a browser, or serve the folder with any static file server.

## Suggested next steps

1. Deploy the Anchor program and copy the program ID.
2. Create the SPL token mint and metadata.
3. Initialize the launch state from the owner wallet.
4. Start the launch with a short delay.
5. Add the token details to the launch page once deployed.
